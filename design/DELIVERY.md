# 知乐移动端与下载页验收

2026-10-30。采用 Spotify 启发的黑灰背景、绿色强调和紧凑歌曲列表，使用原创 Z 波形标志；不使用 Spotify 标志。

## 设计参考与实际实现

| 检查项 | 参考 | 实际结果 |
| --- | --- | --- |
| 色彩 | 深黑页面、炭灰面板、绿色强调 | 歌曲菜单、提示、确认、设置、下载管理和空状态均使用深色；危险操作用暗红色 |
| 信息层级 | 封面、歌名、歌手；少量操作 | 手机每行保留播放与更多；次要信息单行截断，音源与时长保留 |
| 操作面板 | 圆角底部面板、图标加文字 | 独立原生 dialog；每项至少 54px；收藏、保存、换源优先；支持 Esc、遮罩关闭和焦点恢复 |
| 空间 | 一行快捷入口，减少按钮堆砌 | 手机入口横向滚动，更多功能归入菜单，歌曲操作不在原行展开 |
| 歌词 | 不遮挡列表 | 新配置与浏览器默认关闭悬浮歌词；用户已明确保存的偏好保留 |
| 下载页 | 左侧文案、右侧手机实拍、大下载按钮 | 真实应用截图；窄屏上下排列；下载按钮 54px，其他架构可展开 |

`mobile-action-sheet-concept.png` 是 ImageGen 生成的布局参考；`mobile-action-sheet-render.png` 是实际页面。实际保留七项歌曲功能，比参考多了浏览器保存、封面及视频入口；通过分组分隔保持清晰。下载页概念中的早期名称已统一替换为用户确定的「知乐 Zhile」，真实产品截图替代概念中的虚构页面。

## 验证

浏览器验证通过 Codex 内置浏览器的 Playwright 接口完成；没有单独的 Browser 插件。测试使用隔离来源 `http://localhost:37890/music/`，不操作用户正在使用的页面。

- 360×800、432×936：无横向溢出；歌曲更多菜单匹配所选歌曲；收藏入口正确打开原有歌单弹窗；关闭恢复焦点及滚动。
- 菜单 → 播放历史 → 清空历史：打开深色确认框，点击取消，记录未删除。
- 设置：悬浮歌词默认关闭；保存显示深色成功提示。下载管理：队列、筛选及空状态均为深色。
- 1280×900：桌面歌曲操作完整保留，无横向溢出。
- 下载页 360×800、432×936、1440×1050：图片加载成功、内容无溢出、其他安装包选项可展开。
- 页面标题正确、内容非空、无框架错误覆盖层；最终浏览器控制台未捕获 error/warn。
- `node --check internal/web/templates/static/js/app.js`、`go test ./core ./internal/web`、Web 可执行文件构建通过。
- 打包工具编译通过。其 X11 端到端测试依赖未提供的 `internal/normal` 测试程序，在本地无法运行；Android 构建、签名、应用身份与内置音频工具由 GitHub Actions 单独检查。

尚未完成 Android 真机安装、后台播放和各种来源下载的端到端测试。音乐来源可用性会随网络及平台权限变化。本次未为验证界面下载歌曲。
